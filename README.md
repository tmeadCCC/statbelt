# STATBELT Utility - the Statistical Basics Exploratory Learning Tool

From Stat-Man's Utility Belt! A free, single-page statistics tool for the classroom: a data sheet, descriptive statistics, graphs, probability calculators and hypothesis tests. Nothing students type leaves their browser.

- `index.html` is the tool.
- `guide.html` is the User's Guide.
